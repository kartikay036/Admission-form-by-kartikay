#Project Title:
School Admission Form (HTML & CSS)

#Project Description:
The School Admission Form project is a static web page designed using HTML and CSS to collect essential information from students seeking admission. The form provides a clean and user-friendly interface where applicants can enter their personal, academic, and contact details. This project demonstrates the use of HTML form elements along with CSS for styling and layout, focusing on frontend design only.

While it does not include backend functionality (like storing data), it effectively showcases how forms can be structured and styled for real-world use cases.

#Key Features:
Structured form layout using semantic HTML

Input fields for name, date of birth, class, address, contact info, etc.

Radio buttons, checkboxes, and dropdowns for selection

Form validation using HTML5 attributes (e.g., required, email)

Responsive and visually appealing design with CSS

Submit and reset buttons

#Technologies Used:
HTML5 – for creating the structure and form fields

CSS3 – for styling the form, layout, and responsiveness
